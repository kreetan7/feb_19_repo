# Color Picker Card Project

A simple interactive web project that allows users to change the background color of a card by selecting from multiple color options. Built with **HTML**, **CSS**, and **JavaScript**.

---

## 🎨 Features

- Interactive color buttons to change the card background.
- Displays the currently selected color code.
- Smooth transitions and hover effects on buttons.
- Fully responsive design.

---

## 🛠️ Technologies Used

- **HTML** – Structure of the card and buttons.
- **CSS** – Styling, hover effects, and responsive design.
- **JavaScript** – Dynamic color changes and updating the color code.
